# Validation Constitution

# 驗證憲章 v0.1

本文件定義：

- world legality
- simulation validation
- runtime verification
- asset validation
- stability validation
- publish validation rules

本文件為：

# Simulation-first Runtime 的合法性與驗證規格來源。

---

# 1. Core Principle

本專案：

不允許：

```txt
未驗證世界直接成為 canonical runtime
```

---

# 2. Validation Purpose

Validation：

目的為：

- 世界一致性
- semantic consistency
- structural stability
- deterministic safety
- runtime legality

---

# 3. Canonical Validation

所有 canonical runtime asset：

應允許：

- validation
- verification
- replay inspection
- semantic inspection

禁止：

```txt
無法驗證的 canonical runtime state
```

---

# 4. World Legality

世界：

不得違反：

- authority constitution
- spatial constitution
- runtime constitution
- material constitution
- simulation ABI

禁止：

- infinite energy state
- unstable orbital state
- invalid material semantics
- non-deterministic canonical runtime

除非：

被特殊 simulation rule 明確允許。

---

# 5. Structural Validation

所有大型結構：

應允許：

- stress validation
- fracture validation
- thermal validation
- stability validation

避免：

```txt
無法收斂的結構狀態
```

---

# 6. Material Validation

Material：

應允許：

- semantic validation
- energy validation
- stability validation
- runtime compatibility validation

避免：

- semantic conflict
- undefined field meaning
- unstable runtime approximation

---

# 7. Runtime Validation

Runtime：

應允許：

- deterministic replay
- synchronization verification
- authority verification
- streaming validation
- residency validation

---

# 8. Distributed Validation

Distributed Simulation：

必須允許：

- authority validation
- synchronization validation
- serialization validation
- replay validation

避免：

```txt
隱性 runtime divergence
```

---

# 9. Validation Authority

Validation：

不得由：

- renderer
- gameplay
- presentation layer

單獨定義。

Validation：

必須遵守：

- canonical constitutions
- runtime governance
- simulation ABI

---

# 10. Publish Validation

所有 publishable runtime asset：

在進入 canonical runtime 前：

應允許：

- semantic validation
- runtime validation
- deterministic validation
- streaming validation
- authority validation

---

# 11. Final Principle

Validation：

不是 debug feature。

Validation：

是：

# 世界合法性與 runtime 一致性的核心治理系統。
