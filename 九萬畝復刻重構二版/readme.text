
九萬畝：專案架構與核心功能說明 (重構版)
歡迎來到《九萬畝》專案！經過我們共同的努力，這個專案已經從一個原型，蛻變為一個擁有專業架構、具備高度可擴展性的 4X 即時戰略遊戲框架。本文件將詳細闡述當前的核心功能、設計哲學以及未來的開發藍圖。

一、核心功能與設計哲學
我們目前的架構，已經實現了一個動態且完整的遊戲循環，其核心設計圍繞以下幾點展開：

1. 動態世界與城市模板
遊戲不再是靜態的開局。我們引入了「城市模板」(CITY_TEMPLATE) 的概念，這徹底改變了遊戲的基礎：

動態實例化：玩家的初始城市，是在遊戲開始時由 createNewCityInstance 函式根據模板動態創建的。這意味著每個城市（包括您未來建造的分城）都擁有獨一無二的 ID 和標準化的初始配置。

隨機出生點：generateWorldMapData 函式會為這個動態創建的初始城市，在廣大的世界地圖上尋找一個安全的隨機出生點，確保了每次開局的獨特性。

2. 完整且統一的單位生命週期
我們建立了一個無縫的單位生命週期管理系統，確保每一個士兵從誕生到部署，其資料都是一致且唯一的：

整合式招募：招募功能已從過去獨立的彈窗，無縫整合進了兵營、馬廄等建築的「功能」分頁中，UI/UX 更加流暢。

獨立訓練佇列：每個招募建築都擁有自己獨立的訓練佇列，互不干擾。

唯一 ID 追蹤：從點擊「訓練」的那一刻起，每個單位就被賦予一個全域唯一的 ID。這個 ID 會伴隨它進入「部隊列表」，並最終部署到「戰場地圖」上，徹底杜絕了資料錯亂的可能。

智慧化部署：單位訓練完成後，battleMapLogic 中的部署算法會自動為其在城外尋找一個可用的出生點，並將其部署到戰場上。如果戰場已滿，單位會安全地進入您的後備部隊，並給予明確提示。

3. 三層嵌套式地圖系統
遊戲世界由三種不同層級的地圖構成，各司其職：

世界地圖 (60x60)：最高層級的戰略地圖。這裡是您探索世界、佔領資源、擴張領土、以及向其他玩家城池進軍的舞台。

城市地圖 (17x17)：您的城內視圖。在這裡進行建築升級、科技研發、資源管理和部隊招募。城牆和城門作為可被攻擊的防禦工事，是這個場景的核心。

資源戰鬥地圖 (11x11)：當您在世界地圖上對一個資源點（如礦場、糧田）發起爭奪時，就會進入這個獨立的戰術戰鬥場景。

4. AI 戰鬥系統與建築傷害模型
我們已經植入了一套初步但完整的 AI 作戰系統：

智慧尋路：AI 單位能夠透過 battleMapLogic.findPath 函式，識別並繞過城牆等障礙物，並利用「城門」作為攻擊的突破口。

目標鎖定：AI 會優先攻擊離它最近的敵方單位，如果沒有單位，則會將敵方建築（特別是城門）作為目標。

建築傷害模型：我們建立了兵種類別克制關係。combatSystem 的攻擊邏輯會判斷攻擊者的類型：

器械單位：對帶有 building 標籤的目標（如城牆）造成 3 點固定傷害。

其他單位：對建築只會造成 1 點傷害。
這為遊戲的攻城策略打下了堅實的基礎。

二、後續拓展方向
基於當前穩固的架構，我們可以充滿信心地規劃以下激動人心的功能：

1. 佔領與擴張 (Occupation & Expansion)
這是 4X 遊戲的核心。下一步，我們可以在世界地圖上實現「佔領」功能：

實作「佔領」動作：允許玩家派遣部隊去佔領世界地圖上的無主地塊。

啟用「修建城市」：當玩家成功佔領一片 2x2 的連續土地後，在該地塊的互動選單中，會出現一個新的按鈕：「修建城市」。

動態創建分城：點擊該按鈕後，系統會再次呼叫 createNewCityInstance 函式，使用 CITY_TEMPLATE 在這個新的位置上，為玩家創建一座全新的分城。

2. 真實的資源系統
讓資源點不再只是地圖上的裝飾：

資源產出：佔領世界地圖上的資源點（糧田、伐木場、採石場）後，系統應根據資源點的等級，為玩家定時增加對應的資源存量。

消耗與循環：將這些資源（糧食、木材、石頭）與建築升級、單位招募、科技研發的成本完全掛鉤，形成完整的經濟循環。

3. 科技樹與裝備系統
深化遊戲的策略維度：

科技研發：實作「研究所」的功能，設計一個科技樹。玩家可以投入資源和時間來解鎖更高級的兵種、新的建築或全域增益效果（政策）。

裝備鍛造：實作「鐵匠鋪」的功能，允許玩家消耗資源來鍛造武器、護甲等裝備，並將這些裝備配置給您的部隊，進一步提升其作戰能力。

4. PVP 與聯盟系統
將遊戲從單機體驗推向多人互動：

玩家間的戰鬥：當前的 ownerId 系統已經為 PVP 打好了基礎。下一步是允許玩家的部隊在世界地圖上移動，並對其他玩家的城市發動攻擊。

聯盟功能：實作「大使館」的功能，允許玩家創建或加入聯盟。聯盟成員之間可以互相派遣援軍、共享資源、集結攻打強大的敵人。

三、專案檔案結構回顧
